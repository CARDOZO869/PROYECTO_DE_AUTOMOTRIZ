# PROYECTO_DE_AUTOMOTRIZ
Sistema web que optimiza todas las operaciones de tu taller automotriz en un solo lugar: desde la recepción y evaluación del vehículo, hasta la asignación de mecánicos y el seguimiento de las reparaciones en tiempo real. Incluye control exhaustivo de intervenciones, gestión de garantías y un expediente clínico histórico para cada automóvil
